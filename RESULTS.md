## Statistical experiments (RV-018 / RV-020 / RV-021)

`python3 lab/stat_experiments.py` runs a real **40-seed** experiment — each
trial is a live `authz` scan of a randomly configured target — and the harness
statistical oracle (Mann-Whitney U, ≥20 seeds, Wilson 95% CIs) scores three
comparisons. Report: [`reports/stat/report.md`](reports/stat/report.md).

| Scenario | Comparison | mean A vs B | p (2-sided) | Significant |
|----------|-----------|-------------|-------------|-------------|
| RV-018 | scanner correctness vs status-only baseline | 1.00 vs 0.68 | 9.3e-05 | yes ✅ |
| RV-020 | corrected vs naive (attempted=achieved) labeling | 1.00 vs 0.70 | 0.00020 | yes ✅ |
| RV-021 | deduped vs raw (×reproductions) finding count | 0.85 vs 2.65 | 0.0245 | yes ✅ |

All three pass the ≥20-seed statistical gate on real scan data: the scanner
catches write-only BOLA a read-based baseline misses; naive labeling that counts
an attempted-but-scope-blocked attack as a required detection lowers measured
accuracy; and counting each reproduction instead of deduping inflates the metric.

## Integrated live lab (end-to-end, not unit tests)

`python3 lab/live_lab.py` runs the `authz-target` reference API over a real
socket in each vulnerability mode, scans it with the built Rust `authz` binary,
and scores the live SARIF/JSON findings against per-mode ground truth with the
TSG-1 oracles. Report: [`reports/live-lab/report.md`](reports/live-lab/report.md).

**8/8 modes scored as expected:**

| Mode | Server | Scope | Verified findings | Violation | Result |
|------|--------|-------|-------------------|-----------|--------|
| none (hardened) | none | test_owned_only | 0 | — | ✅ zero findings (FP budget) |

## Honest limits

- A green suite means **"survived everything we actually ran"**, never "secure"
  and never "all 326 scenarios executed". Per TSG-1 (Nasr et al. 2510.09023;
  Bhagwatkar et al. 2510.05244), no fixed corpus certifies robustness; the
  adaptive twins and the co-evolving red-team exist precisely because a static
  pass is provisional.
- The 79 conformance-test-backed PASSes show that the built control has passing
  tests for the scenario's property, and no more. Live end-to-end evidence is
  separate: the integrated live lab (8 modes), the 40-seed statistical
  experiments and the fair differential. Each is reported in its own section.
- The guide's prose says "286 scenarios" but enumerates **326**; the registry
  keeps all 326 (per-component counts match the guide's G.1 matrix).
